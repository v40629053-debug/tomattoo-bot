# ToMattoo Bot — деплой-пакет

Telegram-бот кулинарной школы ToMattoo. Собирает заявки (согласие на ПД, имя,
телефон, комментарий), помогает подобрать курс по анкете и передаёт лиды в
Битрикс24.

## Что внутри

- `bot.py` — логика бота (меню, заявки, подбор курсов, передача лидов в CRM).
- `config.py` — конфигурация. **Секреты НЕ зашиты в код** — читаются из переменных
  окружения (и из файла `.env` для локального запуска).
- `requirements.txt` — зависимости (python-telegram-bot 13.7, requests).
- `resources/` — каталог курсов (PDF) и фото основателя.
- `start.sh` — установка зависимостей и запуск бота (для Render).
- `.env.example` — шаблон переменных окружения.

## Переменные окружения (задайте в панели Render > Environment)

| Переменная                  | Описание                                     |
|-----------------------------|----------------------------------------------|
| `TELEGRAM_BOT_TOKEN`        | Токен бота от @BotFather                     |
| `BITRIX24_WEBHOOK_BASE`     | База вебхука Битрикс24 (без метода)          |
| `BITRIX24_USER_ID`          | ID ответственного (по умолчанию 1)           |
| `BITRIX24_SOURCE_ID`        | Источник заявки (по умолчанию TG)            |

## Локальный запуск (Windows)

1. Скопируйте `.env.example` в `.env` и впишите реальные значения.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Запустите: `python bot.py` (держите окно открытым).

## Деплой на Render

1. Создайте репозиторий на GitHub и загрузите файлы этой папки.
   **Не** загружайте `.env` (он в `.gitignore`).
2. В Render: **New > Web Service**, подключите репозиторий.
3. Настройки:
   - Name: `tomattoo-bot`
   - Runtime: Python 3
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python bot.py`
   - Plan: **Free**
4. Во вкладке **Environment** добавьте переменные из таблицы выше.
5. Нажмите **Deploy**. После успешного деплоя бот работает 24/7.
   (На бесплатном тарифе после простоя первое сообщение может прийти с задержкой.)
